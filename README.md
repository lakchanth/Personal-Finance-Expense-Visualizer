# 💳 Personal Finance & Smart Expense Visualizer

A lightweight Python-based web dashboard designed to track daily expenses and automatically generate visual analytics (pie charts and bar charts) to monitor monthly spending habits.

## 🚀 Tech Stack
* **Python** (Core logic)
* **Pandas** (Data manipulation and processing)
* **Matplotlib** (Data visualization)
* **Streamlit** (Interactive web dashboard interface)

## ⚙️ How to Run Locally

1. Clone or download this repository.
2. Install the required dependencies via terminal:
   ```bash
   pip install pandas matplotlib streamlit
3. Run the application:
   ```bash
   python -m streamlit run app.py
